首页 / 设置

设置与数据

数据全部保存在本机浏览器中。导出备份文件（可放入坚果云等同步盘）即可在另一台设备导入，继续之前的进度。

数据概况
云同步
同步服务器地址
你的 Cloudflare Worker 地址（部署流程见 docs/deploy-cloudflare.md）。
同步密钥（远端）
粘贴另一台设备已生成的密钥；首次使用请点下方「生成新密钥」。
本机绑定密钥
当前设备正在使用的密钥（只读，由上方绑定或生成而来）。
（未绑定）
未同步
自动同步
开启后练习数据自动推送；关闭则仅通过「立即同步」手动同步。
语音朗读
作答后自动朗读
作答后自动朗读字词的普通话读音，帮助建立听觉印象；作答完成后可点词语旁的 🔉 图标反复重听。使用设备自带语音引擎，无需联网。
记忆调度（FSRS）
智能复习
按记忆曲线安排复习：到期的字优先出现，生疏的字复习更频繁、熟练的字间隔拉长。关闭则回到纯随机出题。
备份与迁移
导出数据
打包全部学习记录为 JSON 文件，可在任意设备导入恢复。
导入数据
从备份文件恢复；与本地已有数据合并，不会覆盖丢失。
清除本地数据
删除本机全部练习记录、密钥与同步配置（云端数据不受影响）。用于换人使用/重新开始。
使用提示
  • 数据存于本浏览器，清除浏览器数据会一并删除——请定期导出备份。
  • 多设备同步：把导出文件放入坚果云同步文件夹，另一台设备导入即可；两端数据会自动合并。
  • 答题流水（对/错每次作答）与字卡状态都会完整备份，供记忆模型使用。
