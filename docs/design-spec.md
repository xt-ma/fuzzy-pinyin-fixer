### 1.2 字体

- 字体栈（antd 默认，无需引入外部字体）：
  `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 字号阶梯（含用途）：

| 级别 | 字号/行高 | 用途 |
|---|---|---|
| 标题页 | 20px / 1.5 | 页面大标题（如「选择练习模式」） |
| 正文 | 14px / 1.5715 | 默认正文、按钮、表格 |
| 辅助 | 12px | Tag、表头提示、次要信息 |

## 2. 全局布局规范

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏 Header 64px #001529                                    │
│ [拼] 模糊音克星   练习|统计|已掌握|错题本      v1.0·本地数据   │
├──────────┬─────────────────────────────────────────────────┤
│ Sider    │ 内容区 Content（padding 24px，页面底 #F5F5F5）     │
│ 200px    │ ┌─────────────────────────────────────────────┐ │
│ 白底     │ │ 页面容器 Page（白底 8px 圆角，max-w 1160）      │ │
│ 菜单项   │ │  面包屑 / 页面标题 / 内容区块                  │ │
│ 8px 圆角 │ │                                             │ │
│ 选中=蓝底│ └─────────────────────────────────────────────┘ │
└──────────┴─────────────────────────────────────────────────┘
```

- **顶栏**：高度 64px、深色 `#001529`；左侧 logo（28×28 主蓝圆角块 + 白色「拼」字）+ 品牌名；导航 4 项（练习/统计/已掌握/错题本），当前项白色 + 底部 2px 主蓝下划线。
- **侧栏 Sider**：宽 200px、白底、右分割线；菜单项高 40px、圆角 6px，hover 与选中均为 `#E6F4FF` 底 + 主蓝字。
- **页面容器**：白底卡片（max-width 1160px 居中）、padding 24px、阴影 `--shadow-1`。
- **响应式**：窗口 < 900px 时 Sider 隐藏、导航收为顶栏下拉；答题内容保持窄列居中。

## 3. 组件规范

| 组件 | 规范要点 |
|---|---|
| **Button** | 高度 32px（lg 40 / xl 48），圆角 6px；主操作 `primary` 蓝底白字；次级 `default` 白底；hover 变主蓝描边；答题选项用大按钮（64px 高） |
| **Card** | 白底、8px 圆角、`--shadow-1`；hoverable 时抬升 + 主蓝描边 |
| **Tag** | 高 22px、圆角 4px；音对三色按映射表；状态绿/红按语义 |
| **Progress** | 高 8px（答题进度 6px），圆角全圆；颜色按音对映射或语义 |

| **Table** | 表头 `#FAFAFA` 底 500 字重、行 hover `#FAFAFA`；目标字列 16px 加粗；操作列文字链接（危险操作红） |

| **Segmented** | 分段控件：底 `rgba(0,0,0,.04)`，选中段白底阴影 |

## 4. 页面与交互说明

### 4.1 首页（c-home.html）

- **布局**：面包屑 → 标题 → 4 张音对卡（in/ing 橙、en/eng 紫、l/n 青、综合随机主蓝大卡）→ 4 个统计卡 → 操作行（开始综合练习 / 错题重练 + 题量 Segmented）→ 最近练习表。
- **交互**：
  1. 点击音对卡 → 进入答题页，锁定该音对出题（卡片 hover 抬升提示可点）；
  2. 「综合随机」与 3 个专项平级，是每天主入口；
  3. 题量 Segmented（5/10/20）写入 `settings`，所有模式生效；
  4. 最近练习表展示 `history` 最近 4 条。

### 4.2 答题页（c-quiz.html）—— 核心页面

- **布局**：工具条（返回 / 进度条「in/ing 专项 · 3/10」/ 音对 Tag）→ 居中答题卡（提示行 → 整词大字 → 提问 → 两个大选项 → 反馈区）。
- **目标字高亮**：整词 44px、字距 8px；目标字 `#1677FF` + 3px 下划线（下偏移 8px），其余字常规色。
- **选项**：220×64 大按钮，拼音 24px + 韵母小标签（in/ing）；**差异韵母（`n`/`ng`）加粗高亮**。
- **反馈流程**：
  1. 答对 → 正确选项变绿底绿字、错误选项变红（对照）；反馈条「回答正确！in 是前鼻音…」；浮现「标记已掌握，不再出现」次按钮（可跳过）；**1 秒后自动下一题**；
  2. 答错 → 正确选项绿、所选项红；反馈条「回答错误，正确读音为 jīn」+ 提示「已自动加入错题本」；浮现「查看错题本 / 继续下一题」；
  3. 键盘：`1`/`2` 或方向键选答案、`Enter` 确认（无障碍要求）。
- **数据**：答对写入临时记录，点击「已掌握」才写入 `mastered`；答错写入 `wrongBook`（去重累计次数）；进度条 = 当前题号/总题数。

### 4.3 轮末复盘（c-result.html）

- **布局**：大数字正确率（64px）→ 进度条 → 操作（错题重练 / 再练一轮 / 查看统计）→ 本轮错题表。
- **交互**：本轮结束自动进入；「错题重练」仅用本轮错字重新出题；「再练一轮」同参数新开一轮；错题表含"你的选择/正确读音"对照。

### 4.4 统计（c-stats.html）

- **布局**：时间 Segmented（7 天/30 天）→ 4 统计卡 → 折线（7 天趋势，SVG 或图表库）→ 音对分布（三色进度条 + 字数组内比）。
- **交互**：切换时间范围重算趋势与分布；趋势图末端圆点标注今日正确率。

### 4.5 已掌握（c-mastered.html）

- **布局**：搜索框 + 进度（已掌握 128/600 ≈ 21%）+ 音对筛选 Tag + 字表（字/词语/音对/读音/时间/撤回）。
- **交互**：筛选 Tag 单点切换；「撤回」弹出 Popconfirm 二次确认；撤回后该字回出题池。

### 4.6 错题本（c-wrongbook.html）

- **布局**：标题 + 「一键重练全部（12 题）」→ 错题表（字/词语/音对/你的选择/正确/出错次数/最近出错/操作）。
- **交互**：去重累积（同一字只留一条、累计次数）；「重练」单字进入答题页；「移除」二次确认；**连续答对 2 次自动移出**或手动移除。

## 6. 实现注意事项

1. **高保真稿的 CSS**（`c-base.css`）即为 tokens 的参考实现；产品实现时建议用 antd `ConfigProvider` 的 theme token 或同名 CSS 变量直接复用。
2. 拼音带声调由系统字体渲染即可，无需引入拼音字体。
3. 无图表库时，7 天趋势折线用 SVG polyline 实现（高保真稿已给出示例）。
4. 数据层命名（`wrongBook` / `mastered` / `history` / `settings`）与 PRD 保持一致。
