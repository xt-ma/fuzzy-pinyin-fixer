# 系统学习内容调研与课程体系草案

> 背景：项目方向调整为「系统学习为主、做题退居巩固环节」。本文回答：网上有哪些现成内容可用、缺什么、内容体系怎么搭。
> 调研时间：2026-09-20。

## 一、现成内容盘点

### A. 发音正音教程（原理层）——现成内容多、质量好，但表述有版权

| 资源 | 内容要点 | 可用性 |
| --- | --- | --- |
| 知乎专栏《韵母篇：前后鼻音不分怎么办，5步纠音》 | an/ang、en/eng、in/ing 三对的前后鼻音发音位置与规则、5步纠音法 | 事实可借鉴自写，全文不可搬 |
| 中国教育在线《普通话前后鼻音总读混？in和ing这样分》 | 成对练习法：金—京、林—铃、亲—清 / 分—风、真—争、陈—成 | 同上 |
| 新东方《如何区分前后鼻音》 | ing 可夸张成 ieng 帮助体会；训练顺序 an/ang→en/eng→in/ing | 同上 |
| 山西财大继教院《声母发音训练：n与l的对比》 | n/l 同为舌尖中音、部位相同方法不同：n 软腭降气流走鼻腔，l 软腭升气流走舌两侧；捏鼻自测法 | 高校公开页面，事实自写 |
| B站/爱奇艺 | 舌位动图、跟读训练、nl 专集视频 | 可作外链推荐 |
| 普通话训练教材（马显彬《普通话训练教程》等） | 标准章节体系：绪论→声母→韵母→声调→音变→朗读→说话＋词语表；「方言辨正」是固定模块 | 体系结构可参照 |

### B. 字族/声旁识字材料——有体系但错位（面向小学生/繁体区/识字启蒙）

| 资源 | 内容 | 可用性 |
| --- | --- | --- |
| 香港教育局《漢字真有趣》 | 免费官方资源：字族韵文（青字歌等）、部件学习 | 免费官方，可参考形式与繁简转换 |
| 台湾教育云《字族識字教學法》 | 四分类：同音字族/破音字族/同部件字族/同部首字族（1-4年级） | 分类学可借鉴 |
| 《字族識字活用寶典：念歌謠學語文》（台湾书） | 每首字族歌后按部首列生字释义 | 商业书，仅思路参照 |
| 人教社部编教材识字编写思路 | 用形声字声旁规律猜读生字 | 官方解读，思路参照 |
| 字族文识字法（四川井研，60年代起） | 声旁归类编成韵文课文集中识字 | 方法论出处 |
| 关之英《字族文識字教學探究》（港教大） | 教学实证 | 理论支撑 |

### C. 成品 App（产品参照，非内容来源）

- 畅言普通话（科大讯飞）：语音诊断→定制课程，「易混淆音对比训练」专项模块＋直播课——验证了「专项对比训练」这一需求形态。
- 普通话学习类综合 App：按大纲顺序的系统课程＋跟读评分。

### D. 练习素材（绕口令/词表）——民间流传，版权风险低

- n/l：《牛郎恋刘娘》（牛郎恋刘娘，牛郎牛年恋刘娘。刘娘念牛郎，刘娘连连念牛郎……）
- 通用：《八百标兵》《白石塔》《老六放牛》等（百度汉语/知乎 110 首合集）
- 最小对立成对词：牛—流、男—蓝、你—李；亲身/清真（前）vs 长城/山冈（后）

## 二、缺口分析

**没有可直接拿来用的完整课程**。现有内容两极：
1. 正音教程只讲「怎么发」（舌位/气流），不讲「哪些字读哪边」——恰恰是声旁字族能补的；
2. 字族识字材料面向小学识字启蒙（且多为繁体语境），不讲发音矫正。

「声旁字族规律 × 成人模糊音矫正」的交叉领域是空白——这正是本项目独有数据（`docs/phonetic-series.json`，109 系列/666 字/反例清单）能直接填充的位置。

## 三、建议的课程体系

→ v1 五单元草案已废弃（含正音原理单元）；**v2 见 [curriculum-outline.md](curriculum-outline.md)**：砍掉发音原理（用户会发音，缺的是「字→读哪边」），主线改为「规律带一族 → 例外防反噬 → 对比防干扰」三步法 + 巩固闭环，焦点=区分、减量、增效。

版权策略：学理自写（发音事实不受版权保护）、绕口令用民间版本、字族数据用自有分析产出、外部优质内容（知乎专栏/香港教育局/B站视频）以推荐链接形式收纳。
